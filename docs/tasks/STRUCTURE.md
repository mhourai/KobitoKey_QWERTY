# リポジトリ構造の宣言

このファイルは、リポジトリ作成時またはタスク管理導入時に必ず作成し、
以降のタスク配置ルールの基準とする。

## 判定
- [x] パターンA: このリポジトリは単一プロジェクトである
- [ ] パターンB: このリポジトリは複数の独立したサブプロジェクトを意図的に含む

## 補足
- 本リポジトリは ZMK ファームウェア用コンフィグ単体(`config/`)であり、
  `keymap-drawer/` は keymap-drawer により自動生成される成果物(独立モジュールではない)。
- ブランチ(`main`, `no-led-widget`, `prospector-support`, `no-cursor-decel` 等)は
  同一プロジェクト内の診断・機能バリアントでありサブプロジェクトではない。
- tasks.jsonl はリポジトリ直下 `docs/tasks/tasks.jsonl` に配置する。

## パターンBの場合、サブプロジェクト一覧
| サブプロジェクト名 | パス | 説明 |
|---|---|---|
| (なし) | - | - |

## 新しいサブプロジェクトを追加する場合
このファイルの一覧を更新し、対応する docs/tasks/tasks.jsonl を新設すること。
既存のtasks.jsonlに混在させることは禁止する。
